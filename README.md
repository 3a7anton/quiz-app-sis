# QuizBlitz

A real-time multiplayer quiz game powered by Supabase. Host a game or join your friends for an exciting quiz battle!

## Features

- **Live Multiplayer** - Real-time gameplay with friends using Supabase
- **Host or Join** - Create your own quiz room or join an existing one
- **Interactive UI** - Modern, responsive design with smooth animations
- **Real-time Leaderboard** - Track scores as the game progresses

## Tech Stack

- HTML5
- Vanilla JavaScript
- Supabase (Real-time database)
- CSS3 with custom properties

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Set up your Supabase project and configure the credentials
4. Start hosting or joining quiz games!
